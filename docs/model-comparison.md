# Сравнение вариантов модели

Продукт не привязан к одной модели. Правила в коде одни и те же, меняется только настройка в `.env`. Каждую модель мы проверяем одним и тем же набором: 21 контрольный вопрос по руководствам и сценарии защиты. Так заказчик выбирает вариант по измеренному качеству и стоимости, а не по названию модели.

## Три уровня закрытости данных

| Вариант | Где обрабатываются запросы | Оплата | Настройка |
|---|---|---|---|
| Зарубежная модель через шлюз | За пределами России | За токены, в рублях через шлюз | `LLM_PROVIDER=anthropic` |
| Российское облако | В России | За токены | `LLM_PROVIDER=openai`, адрес Yandex AI Studio |
| Локальная модель | На сервере заказчика | Сервер с видеокартой | `LLM_PROVIDER=openai`, адрес своего сервера |

Что именно уходит наружу в каждом варианте и что остаётся на сервере продукта, описано в [local-model.md](local-model.md).

Про строки таблицы:

- **Claude Haiku 5.5.** Младшая модель семейства прошла порог приёмки, поэтому она и стоит на стенде. В первом прогоне было две неудачи в проверках качества, после исправлений повторный прогон дал 21 из 21: ответ на хинди получился наполовину на русском (выбор языков после этого убран, система работает только на русском), и однажды модель не стала собирать заявку, потому что по проверке уже были заявки от прошлых прогонов (исправлено в инструкции). Старшие модели прогонять имеет смысл, только если вопросы экспертов окажутся труднее наших.
- **YandexGPT Pro 5.1.** Российская модель. Окно контекста 32 тысячи токенов по документации Yandex AI Studio, для нашего запроса это близко к пределу: первый вызов занимает около 8 тысяч и растёт с результатами поиска.
- **Qwen3.6 35B.** Открытая модель того класса, который можно поставить на сервер заказчика. Прогон через облако показывает, чего ждать от локального варианта, без покупки сервера. Качество у себя на сервере может отличаться из-за сжатия модели.
- **Qwen2.5 7B.** Нижняя граница. Порог 18 из 21 не пройден, как рабочий вариант не рекомендуется.

Порог приёмки одинаковый для всех: не меньше 18 вопросов из 21, все три отказа и случай с расхождением документов обязательны, ошибок в правилах кода нет.

## Что уже можно сказать

- Задача агента - внимательное чтение, а не сложное рассуждение: выбрать инструмент, составить запрос к поиску, дословно процитировать страницу, взять с неё нужное число. Самое трудное для слабой модели - последние два пункта и противоречия между документами.
- Код страхует от выдуманных ссылок и нормативов при любой модели, поэтому слабая модель ошибается чаще в сторону отказа, чем в сторону неверного ответа. От выбора не того числа с правильной страницы код не страхует.
- Маленькая модель на 7 млрд параметров не справляется. Хватит ли модели на 30-35 млрд, покажет только прогон.
- Младшая модель Claude справляется полностью. Значит, для этой задачи самая дорогая модель не нужна: процедура по машине стоит около 6,65 ₽ без НДС, каждый вопрос механика около 0,92 ₽.
